3.0 Purpose

This document defines how MS Portfolio looks, feels, speaks, and is recognized.

While:

Volume 0 defined who we are.
Volume 1 defined why the portfolio exists.
Volume 2 defined how users experience it.

Volume 3 defines

How the portfolio expresses its personality visually.

Every pixel, color, font, spacing decision, animation, icon, and image style must originate from this document.

This is the DNA of the entire design system.

3.1 Brand Philosophy

The portfolio should not resemble a template.

It should resemble the digital workspace of someone who thinks in systems.

The design language must communicate:

Engineering precision
Creative maturity
Modern craftsmanship
Confidence without arrogance
Simplicity without emptiness
Technical depth without complexity

The overall feeling should be:

"Minimal on the surface.

Sophisticated underneath."

3.11 Color Philosophy

Color is communication.

Never decoration.

Instead of vibrant interfaces,

use restrained color with meaningful emphasis.

Rule:

Neutral dominates.

Accent guides.

Color should create focus,

not excitement.

3.14 Color Rules

Accent color should never exceed 10% of the viewport.

Avoid rainbow palettes.

Avoid multiple competing colors.

Avoid saturated gradients.

3.42 Acceptance Criteria

Volume 3 is complete when:

The brand has a clearly defined personality and visual identity.
A complete design language exists independent of individual screens.
Colors, typography, spacing, and layout systems are documented as reusable tokens.
Visual and interaction rules are consistent across all future components.
Designers and developers can create new screens without inventing new styles.
3.43 Definition of Done (Volume 3)

Volume 3 is complete when every visual decision can be traced back to a documented rule rather than personal preference.

If a new component is introduced, the answer to:

"Which font should I use?"
"Which spacing value should I choose?"
"Which color should this state use?"
"How should this card behave?"
"How should this interaction feel?"

should already exist within this document.
